### GDD Writing (4/7 MVP)

**1. CrazyGames Platform Requirements**
- Two-stage launch model: Basic Launch (M4) → Full Launch (M9)
- SDK v3 integration sequence, required vs. optional calls
- Ad break rules, content policy, technical constraints
- Godot 4.6 single-threaded export confirmed compatible
- File: `design/gdd/crazy-games-platform-requirements.md`

**2. Run Lifecycle**
- Infinite arena loop — no timer, no lives, player-driven shop visits
- Score is persistent currency, never resets between visits
- Start Over: resets score + upgrades, returns to Arena (CG) or Main Menu (Steam)
- SDK hook placement confirmed: gameplayStop before fade, gameplayStart after fade
- Shop classified as non-gameplay screen (enables banner ads in Full Launch)
- File: `design/gdd/run-lifecycle.md`

**3. Main Flow**
- Architecture: `app.tscn` as persistent root; Arena + Shop + ScreenFade as children
- Managers (CrazyGamesManager, SaveSystem, AudioManager) as Autoloads — consistent with existing UpgradeManager
- Transitions: visibility toggles + ScreenFade (≤ 500ms) — zero load time
- Start Over confirmation: overlay within Shop, no scene change
- Save trigger: periodic during arena play (interval TBD in Save System GDD) + on Shop entry + on Start Over
- Note: investigate atomic write strategy for browser-close mid-save scenario
- File: `design/gdd/main-flow.md`

**4. Scoring**
- Hard rule established: **score never decreases**
- Decoupled `is_harmful` from `selection_mode` — prototype uses INTERSECT as proxy; must be refactored before Alpha
- Wipe now triggers with any selection containing a wipe shape (not just gold alone)
- Shape values and multipliers are unbounded (64-bit int)
- "Réduction de pénalité toxique" upgrade removed — no penalty to reduce
- Score display position TBD (candidate: near Shop button)
- Camera shake may conflict with vector aesthetic — flagged for Feedback & Signals GDD
- File: `design/gdd/scoring.md`

## Key Decisions

| Decision | Rationale |
|----------|-----------|
| CG build launches directly into Arena | Instant engagement critical for web platform |
| Score never decreases | Prototype evolved away from penalty; hard rule simplifies design |
| `is_harmful` decoupled from `selection_mode` | Prototype shortcut; full game needs flexible shape type system |
| Wipe triggers with multiple shapes selected | Prototype "gold alone" rule was too restrictive |
| Managers as Autoloads, not app.tscn children | Consistent with UpgradeManager; globally accessible without path lookups |
| Localization added as MVP system | CrazyGames requires English; no hardcoded strings must ship |
| Mid-May as CG launch target | Progress-driven, not hard deadline; part-time schedule acknowledged |
